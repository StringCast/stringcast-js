# StringCast JavaScript packages

Over-the-air localization for web apps — part of [StringCast](https://console.stringcast.app).

| Package | Folder | |
|---|---|---|
| [`@stringcast/web`](https://www.npmjs.com/package/@stringcast/web) | [`web/`](web) | Browser SDK with React bindings |
| [`@stringcast/cli`](https://www.npmjs.com/package/@stringcast/cli) | [`cli/`](cli) | Push and pull string files from CI, Gradle or Xcode |

Docs: https://console.stringcast.app/docs/web · https://console.stringcast.app/docs/cli
